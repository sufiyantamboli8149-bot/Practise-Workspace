# 🍛 Spice Villa Restaurant

A simple and responsive **restaurant website** built using **HTML and CSS**.
The website presents Spice Villa Restaurant with a home section, restaurant information, menu items, and contact details.

## 📱 Responsive Design

The website includes responsive CSS rules for smaller screens.

On mobile devices:

* The navigation header becomes vertical.
* The About section changes to a single-column layout.
* Menu items are displayed in a single column.
* The hero heading becomes smaller.

## 🚀 How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/your-username/spice-villa-restaurant.git
```

2. Open the project folder:

```bash
cd spice-villa-restaurant
```

3. Open `index.html` in your browser.

That's it! No additional dependencies or installation are required.

---

## 🌍 Deploy on GitHub Pages

You can easily host this website using GitHub Pages.

1. Push the project to a GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
5. Click **Save**.
6. GitHub will provide your live website URL.
