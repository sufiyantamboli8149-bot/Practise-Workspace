# 🧮 Calculator

A simple calculator user interface built using **HTML** and **CSS**. This project focuses on creating a clean, responsive, and visually appealing calculator layout.

## 🚀 Features

* Modern calculator design
* Responsive layout
* Number buttons (0–9)
* Basic operator buttons (+, −, ×, ÷)
* Clear (C) button
* Equal (=) button
* Clean and easy-to-read interface

> **Note:** This version is created using only **HTML** and **CSS**, so the buttons are for UI design only and do not perform calculations.

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📁 Project Structure

```text
calculator/
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
